One word, the first that comes to mind — no topic, no explanation, no second draft. See the competition at https://make.fun/bounty/u-0xkianno-one-word-first-thought-106abaf8.

## Run

```sh
python3 main.py
```

This writes the one word to `entry.txt` inside `$ENTRY_OUTPUT_DIR` (default `/output`). Standard library only, no network, deterministic.
